# Kriter DataLab · versión candidata con control de acceso

Aplicación estática que consulta datos comerciales **sintéticos** en PostgreSQL
(Supabase) aplicando autenticación y **Row Level Security**. Cada perfil ve
únicamente las áreas comerciales que tiene asignadas; la autorización se evalúa
en el servidor, no en el navegador.

Sin iniciar sesión se muestra solo el área pública de demostración.
