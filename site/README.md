# Kriter DataLab

Panel interactivo para exploración comercial, desarrollado por **Jesus R.L. Gonzalez**.

**Datos sintéticos.** El conjunto comercial incluido es reproducible y no representa información ni resultados de clientes. La aplicación es estática y ejecuta el procesamiento en el navegador. Los escenarios son análisis de sensibilidad, no pronósticos validados.

Código fuente y documentación: https://github.com/jesusrlgonzalez/Kriter-DataLab-Applied-Data-Science-Decision-Intelligence
