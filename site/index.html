GOBIERNO

Reglas de transformación

Granularidad controlada
Cada registro representa un producto en una semana y un área. No hay subtotales mezclados con transacciones.
Integridad dimensional
Cada producto está vinculado a una sola marca y un segmento; el calendario contiene semanas únicas.
Unidad de medida
Los importes corresponden a unidades de valor ficticias y no se atribuyen a una moneda.
Dimensión territorial
Las áreas comerciales son etiquetas de una operación hipotética, sin geocodificación.
Arquitectura estática
El navegador ejecuta los filtros y los cálculos; la publicación no requiere una API ni base de datos.
Protección de datos
El repositorio público incorpora exclusivamente un dataset sintético creado para probar la experiencia de producto.
ALCANCE

Uso responsable del tablero

Alcance de producto: herramienta de exploración y simulación comercial ejecutada en el navegador. Los datos son sintéticos; las cifras no corresponden a clientes ni actividades de negocio reales. Las proyecciones son hipótesis ajustables, no pronósticos calibrados. Esta versión no incluye autenticación ni ingestión automática de datos.
